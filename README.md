# Studentų pažymių skaičiavimo sistema v0.1

Programa, skirta studentų galutiniams pažymiams skaičiuoti naudojant **C-style masyvus** arba **vektorius** namų darbų pažymiams saugoti. Palaiko rankinį įvedimą, automatinį pažymių generavimą ir du skaičiavimo metodus (vidurkis arba mediana).

---

## 📋 Funkcijos
- **Dvi versijos**:
  - `misri.cpp`: Naudoja C-style masyvus su fiksuotu dydžiu.
  - `vektorine.cpp`: Naudoja dinaminius `std::vector` lankstesniam duomenų saugojimui.
- **Įvesties validacija**:
  - Vardai ir pavardės turi būti sudaryti tik iš raidžių.
  - Pažymiai turi būti sveikieji skaičiai nuo 1 iki 10.
- **Skaičiavimo metodai**:
  - Galutinis pažymys skaičiuojamas naudojant **vidurkį** arba **medianą**.
- **Duomenų generavimas**:
  - Automatiškai sugeneruojami studentų duomenys (vardai, pavardės, pažymiai).
  - Galima nustatyti studentų skaičių ir namų darbų kiekį.
